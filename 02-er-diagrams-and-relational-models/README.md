# 02 — Modelo Entidad–Relación y Modelo Relacional

## Español
Esta sección reúne los materiales de estudio sobre modelado Entidad–Relación, esquemas relacionales, relaciones, claves, cardinalidades y restricciones de integridad.

Los cinco ejercicios prácticos se han organizado de forma independiente en la carpeta [ejercicios/](../ejercicios/README.md). Cada ejercicio dispone de su propio README y de carpetas para diagrama E/R, modelo relacional, scripts SQL, documentación y resultados.

## English
This section contains study materials on Entity–Relationship modelling, relational schemas, relationships, keys, cardinalities and integrity constraints.

The five practical exercises are organised independently in the [ejercicios/](../ejercicios/README.md) directory. Each exercise has its own README and dedicated folders for the E/R diagram, relational model, SQL scripts, documentation and results.
