# Bases de Datos Relacionales y SQL
### SQL & Relational Databases | CIFO La Violeta

[English](#english) · [Español](#español)

A practical learning portfolio documenting database design, relational modelling, SQL development, and the final database project completed as part of the **Programació amb SQL i bases de dades relacionals (IFCD47)** course at **CIFO La Violeta, Barcelona**.

> This repository is a work in progress. Exercises, diagrams, scripts, and project documentation will be added as the course progresses.

## English

### About this repository
This repository brings together practical exercises and projects covering the foundations of relational databases and SQL. It is organised as a portfolio to demonstrate database design, data modelling, query development, and database programming.

### Topics
- Database fundamentals and relational concepts
- Entity–Relationship (ER) diagrams
- Relational models and database normalization
- SQL Data Definition Language (DDL)
- SQL Data Manipulation Language (DML) and queries
- Joins, subqueries, and Common Table Expressions (CTEs)
- Views, functions, triggers, stored procedures, and events
- Database users, roles, and permissions
- Final database project

## Español

### Sobre este repositorio
Este repositorio reúne ejercicios prácticos y proyectos sobre los fundamentos de las bases de datos relacionales y SQL. Está organizado como un portafolio para mostrar diseño de bases de datos, modelado de datos, desarrollo de consultas y programación de bases de datos.

### Contenidos
- Fundamentos de bases de datos y conceptos relacionales
- Diagramas Entidad–Relación (E/R)
- Modelos relacionales y normalización de bases de datos
- Lenguaje SQL de definición de datos (DDL)
- Lenguaje SQL de manipulación de datos (DML) y consultas
- JOIN, subconsultas y expresiones de tabla comunes (CTE)
- Vistas, funciones, triggers, procedimientos almacenados y eventos
- Usuarios, roles y permisos de bases de datos
- Proyecto final de bases de datos

### Estructura del repositorio
La estructura de carpetas está organizada por bloques temáticos. Cada carpeta contendrá los ejercicios, diagramas, scripts SQL y documentación correspondientes.
