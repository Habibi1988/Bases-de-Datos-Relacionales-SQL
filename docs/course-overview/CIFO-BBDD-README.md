# CIFO-BBDD — Bases de Datos Relacionales y SQL

## Español

Portafolio de aprendizaje que documenta el curso de 200 horas de programación de bases de datos y SQL en **CIFO La Violeta, Barcelona, España**. Este repositorio reúne ejercicios de diseño de bases de datos, práctica SQL, tareas del curso y proyectos prácticos a medida que avanza la formación.

> **Estado:** En desarrollo  
> **Lenguaje principal:** SQL  
> **Plataforma de base de datos:** MySQL  
> **Herramientas:** MySQL Workbench, Visual Studio Code

### Estructura del curso
El curso se organiza en cinco unidades formativas (UF), con un total de 200 horas.

| Unidad | Tema | Horas | Objetivos principales |
|---|---|---:|---|
| UF01 | Introducción y diseño de bases de datos relacionales | 30 | Analizar requisitos de información y diseñar bases de datos conceptualmente. |
| UF02 | Modelo Entidad–Relación y normalización | 30 | Crear modelos E/R, transformarlos en modelos relacionales, definir restricciones de integridad y normalizar hasta 3FN. |
| UF03 | Lenguaje de Definición de Datos (DDL) | 40 | Crear y modificar estructuras de bases de datos y definir objetos del esquema. |
| UF04 | Lenguaje de Manipulación de Datos (DML) | 50 | Consultar y manipular datos, trabajar con varias tablas y utilizar agregaciones. |
| UF05 | Programación de bases de datos | 50 | Trabajar con triggers y procedimientos almacenados y estudiar el rendimiento de consultas. |
| **Total** | | **200** | |

A learning portfolio documenting my 200-hour database and SQL programming course at **CIFO La Violeta, Barcelona, Spain**. This repository brings together database design exercises, SQL practice, course assignments and practical projects as I progress through the curriculum.

> **Status:** In progress  
> **Primary language:** SQL

### Course structure
The course is organized into five training units (UF), totaling 200 hours.

| Unit | Topic | Hours | Main learning goals |
|---|---|---:|---|
| UF01 | Introduction and design of relational databases | 30 | Analyze information requirements and design databases conceptually. |
| UF02 | Entity–Relationship model and normalization | 30 | Build E/R models, map them to relational models, define integrity constraints and normalize data up to 3NF. |
| UF03 | Data Definition Language (DDL) | 40 | Create and modify database structures and define schema objects. |
| UF04 | Data Manipulation Language (DML) | 50 | Query and manipulate data, work with multiple tables and use aggregation. |
| UF05 | Database programming | 50 | Work with triggers and stored procedures and study query performance. |
| **Total** | | **200** | |
