# Ejercicio 10 — Vistas, creación de tablas y variables de sesión

[🇪🇸 Español](#español) | [🇬🇧 English](#english)

## Español

Esta carpeta contiene los ejercicios prácticos de SQL del Ejercicio 10, realizados con la base de datos `jardineria`.

### Temas

- Creación y utilización de vistas SQL (`VIEW`)
- Creación de tablas a partir del resultado de consultas
- Variables de sesión
- Filtrado de resultados de vistas mediante variables de sesión
- Creación y eliminación de vistas

### Ejercicios

1. Crear la vista `pedidos_no_entregados`.
2. Crear la vista `listado_pagos_clientes`.
3. Crear la vista `listado_pedidos_clientes`.
4. Utilizar la variable de sesión `@ciudad` para mostrar los clientes de Madrid que han realizado pagos.
5. Cambiar el valor de `@ciudad` a Miami y repetir la consulta.
6. Crear ocho vistas a partir de consultas seleccionadas del Ejercicio 9.
7. Eliminar la vista `listado_pedidos_clientes`.
8. Crear una nueva tabla a partir del resultado de una de las vistas seleccionadas del Ejercicio 9.

### Base de datos

`jardineria`

### Notas

Los scripts SQL y la documentación de apoyo de este ejercicio se irán añadiendo a esta carpeta a medida que se completen los ejercicios.

## English

This folder contains the SQL practice exercises for Exercise 10, using the `jardineria` database.

### Topics

- Creating and using SQL views (`VIEW`)
- Creating tables from query results
- Session variables
- Filtering view results using session variables
- Creating and deleting views

### Exercises

1. Create the `pedidos_no_entregados` view.
2. Create the `listado_pagos_clientes` view.
3. Create the `listado_pedidos_clientes` view.
4. Use the session variable `@ciudad` to list customers from Madrid who have made payments.
5. Change `@ciudad` to Miami and repeat the query.
6. Create eight views based on selected queries from Exercise 9.
7. Delete the `listado_pedidos_clientes` view.
8. Create a new table from the result of a selected Exercise 9 view.

### Database

`jardineria`

### Notes

SQL scripts and supporting documentation for this exercise will be added to this folder as the exercises are completed.
